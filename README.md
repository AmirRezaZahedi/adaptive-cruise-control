# Adaptive Cruise Control (ACC)

A simplified ADAS project built with MATLAB to explore the basic concepts of **Decision, Planning, and Control (DPC)**.

### Features

* Decision layer with `CRUISE`, `FOLLOW`, and `BRAKE` states
* Simple planning / target generation
* PID-based longitudinal control
* Simplified vehicle model
* Multiple ACC driving scenarios
